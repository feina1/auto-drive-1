## 1. 方案选择（每个决策与理由）

| 决策点 | 选择 | 数值 | 理由 |
|---|---|---|---|
| 标签形式 | 时间等距 6 点 | 3 s @ 2 Hz | 控制只要近处；更远的点在弯道转角大、抬高 loss |
| 坐标系 | ego 车体系 | x 前 y 左，m | 与控制器、`record.py`、`train/collect_data.py` 约定一致 |
| 必须的输入 | 图像 + 当前车速（+转向） | proprio 2 维 | 同样画面在 40 与 72 km/h 下首点差 1.8 倍，单帧图像无法区分 |
| 遥测频率 | 10 Hz 全量 | `SIM_DT=0.1` | 与仿真决策周期一致，保证标签插值精度 |
| 图像频率 | 2 Hz | 0.5 s/帧 | 0.5 s 内画面变化已含足够控制信息，样本量 -60%、体积 268 MB |
| 训练数据 | 5 圈变速专家正常行驶 | 40/48/56/64/72 | 覆盖速度泛化；不注入扰动、不筛困难样本 |
| 数据划分 | 按圈 hold-out | 留第 5 圈验证 | 相邻帧只差 0.1/0.5 s，随机划分必然泄漏 |
| 视觉主干 | DINOv3 ViT-S/16 冻结 | 384 维 | 7 千张图微调大模型不划算；先缓存特征，head 迭代快 |
| head | 2 层 MLP | 256 宽，0.17 M | 容量足够拟合 384→12 的映射 |
| 损失 | 加权 SmoothL1 + 平滑 | 见 §5.3 | 近点对控制更重要；平滑项抑制 waypoint 抖动 |
| 控制器 | Pure Pursuit + PID + 曲率限速 | 见 §6 | 可解释、无需训练、对偏离输入天然有拉回 |
| 基线策略 | 冻结 + sha256 + 不变量 | 93 + 4 项 | 保证任何一版实验都能复现与对照 |

## 2. 数据采集（`collect_trajectory.py`）

### 2.1 主循环

- 专家 = 根目录 `pid_demo_autonomous.PathFollower`（Pure Pursuit + PID），沿
  `simple_track_reference_clean.json` 的内侧车道中心线跑；`LapCounter` 计圈，碰撞即中止。
- 每个 `env.step` 记录一帧（10 Hz）：位姿、`speed_kmh`、velocity、`yaw_rate`、`accel_ms2`、
  专家 `steering/throttle/throttle_brake`、`offroad/collision`、`lap/lap_t`、`target_speed_kmh`。
- 多圈：`--laps 5 --speeds 40,48,56,64,72`，每圈开始把目标速度切到对应值，
  沿**同一条连续时间轴**记录，不按圈周期拼接。
- 完圈后**多录 `TAIL_EXTRA_S=6 s`**（> 3 s 时域），这样最后几帧也有真实未来。

### 2.2 图像

- 每 `IMAGE_EVERY_STEPS = 0.5/0.1 = 5` 步抓一帧，640×360、水平 FOV 60°、JPEG q90；
- 命名 `images_trajectory_5laps/frame_{frame_id:07d}.jpg`，帧内写相对路径 `image_path`；
- 无头双相机踩过的三个坑（合并 `record.py` 时同样适用）：

| 坑 | 现象 | 对策 |
|---|---|---|
| 相机被过滤 | `image_observation=False` 时引擎丢弃所有相机 | 配置 `image_observation=True`、`vehicle_config.image_source="rgb_camera"` |
| 传感器不挂车 | 无 main_camera 时读到旧位姿纹理 | 每帧 `cam.track(v.origin, 默认偏移, 默认 HPR)` 后 `renderFrame()`（`traj_utils.capture_rgb`） |
| 离屏无 GL | `nohup` 后台拿不到上下文 | 正常终端运行 |

### 2.3 采集结果（baseline-v2）

36,371 帧 / 3,637.1 s / 7,274 图 / 0 碰撞 / 447 出界帧（1.23%）/ wall 约 245 s。

## 3. 标签生成（`make_waypoints.py`）

对每帧 i：

1. 取未来时刻 `t_i + [0.5, 1.0, …, 3.0]`（`WP_COUNT=6`，`WP_DT=0.5`）；
2. 在整条轨迹的 `(t, x, y)` 上用 `np.interp` 线性插值得到世界点（10 Hz 采样，插值误差可忽略）；
3. 用该帧位姿把世界点旋到 ego 系：`x_e = dx·cosh + dy·sinh`，`y_e = -dx·sinh + dy·cosh`；
4. 圈尾：录制时已多录 6 s，真实未来直接可取；只有最后不足 3 s 的 **30 帧**
   按末帧速度/航向直线延拓（该段是直道）。`extrapolated_points=0`。

校验与产物：

- `spacing_median_rel_err`：相邻 waypoint 间距与 `v×0.5 s` 的相对误差，实测 **0.0001**（阈 0.10）；
- 逐圈 `|wp0|` 中位 = 5.556 / 6.667 / 7.778 / 8.889 / 10.0 m，严格等于 `0.5 s × 均速`；
- 输出 `.npz`（18 字段）+ `_meta.json`（逐圈帧数/图片数/均速/`|wp0|`、相机参数、外推统计）。

划分（写进 npz 供参考，训练栈会按圈重算）：多圈留最后一圈验证；单圈/片段前 90% / 后 10%。

## 4. 数据读取与划分（`training/common.py` / `dataset.py`）

- `Frames(npz)` 轻量视图；`image_abs(i) = npz 目录 / image_path[i]`，所以 npz 与图片目录必须一起搬；
- `lap_split(val_laps)`：先取 `image_mask`（`image_path != ""`），再按圈划分；
  默认 `val_laps = 最后一圈`，5 圈数据 → train 6,178 / val 1,096 带图帧；
- `ImageDataset`：读图 → 缩放到 128×72 → `[0,1]`；训练时 50% 水平翻转，**同时把 waypoint 的 y 取反**；
- `FeatureDataset`：读 384 维缓存，训练时加 `N(0, 0.02²)` 噪声 + 5% 特征 dropout。

## 5. 模型与训练（`training/`）

### 5.1 特征

`extract_features.py`：冻结 ViT-S/16，`feat = (CLS + patch 均值) / 2`，384 维 float32，只算有图帧。
输出缓存含 `features/prop/wp/src_index/speed_kmh/lap/t/image_path/source_npz`。

### 5.2 结构

```
DINOv3 feat[384] ─┐
                  ├─ LayerNorm(386) → Linear(386,256) → GELU → Dropout(0.1)
proprio[2] ───────┘   → Linear(256,256) → GELU → Dropout(0.1) → Linear(256,12) → view(6,2)
```

TinyCNN（4 层 stride-2 卷积 + GAP，约 0.2 M）只用于无 GPU / 无权重时冒烟，不是交付模型。
`load_checkpoint()` 从 ckpt 的 `config` 重建结构，推理端不需要额外参数。

### 5.3 损失与优化

```
per_point = SmoothL1(pred, gt, beta=1).sum(-1)          # [B,6]
loss = mean(per_point × [3.0,2.5,2.0,1.5,1.0,0.8])
     + 0.02 × mean(||wp[k+2] - 2wp[k+1] + wp[k]||²)     # 二阶差分平滑
```

AdamW（lr 3e-4、wd 1e-4）、Cosine 退火到 `lr×0.02`、batch 64、梯度裁剪 5.0、最多 300 epochs；
**按验证圈 ADE 保存最优**（不是按 loss）。checkpoint 里带 `val_laps/zero_prop/train_stride`
等消融开关，`predict.py` 会自动沿用。

## 6. 控制器（`controllers.py`）

输入 `wp_ego [K,2]` + `speed_kmh`，输出 `[steering, throttle_brake]`，每 0.1 s 调一次。

| 环节 | 实现 | 数值 |
|---|---|---|
| 前瞻 | `L = clamp(look_base + look_scale·v, 4, 28)` | 6.0 + 0.35 v |
| 横向 | 在 waypoints 折线上按弧长取前瞻点，自行车模型反解 `δ = atan(2·L_wb·y / L²)` | `L_wb=2.5 m` |
| 转向输出 | `action = δ / 40°`，限幅 | ±0.6（轮胎饱和标定值） |
| 纵向 | 速度 PID | kp 0.15 / ki 0.02 / kd 0.01，积分限 3.0 |
| 弯道限速 | 未来 3 s 内最大曲率 κ：`v ≤ √(lat_acc_max/\|κ\|)` | `lat_acc_max=4.5` |

`kp_steer` 默认 0：ego 系 waypoints 已隐含横向偏移，再加 P 项会重复计数。
`validate_controller.py` 用 GT waypoints 整圈验证时序：采样相位必须恒 0.5 s；
已通过 70 km/h、平均横向 0.02 m、0 碰撞。

## 7. 评测与诊断

| 脚本 | 做什么 | 判据 / 产物 |
|---|---|---|
| `training/predict.py` | 验证圈逐帧预测，分点 RMSE、按圈/速度分桶、最差帧 CSV | ADE < 3 m、FDE < 5 m；`pred_metrics.json` / `pred_arrays.npz` / 两张图 |
| `training/closed_loop.py` | 渲染图 → 模型 → waypoints → 控制器实跑 | 完圈、0 碰撞、平均横向 < 1.5 m；`closed_loop_metrics.json` / `.csv` / `.png` |
| `training/report.py` | 把训练/预测/闭环合成一张版本图 | `reports/vN/summary.png` + `latest/`，含 code fingerprint 与自动诊断 |
| `training/selftest.py` | 无数据自检：反向、控制器、坐标变换 | `SELFTEST PASS` |

闭环里 `--infer-every N` 时，中间 tick 用位姿变换把预测时刻的 waypoints 转到当前 ego 系
（`ego_to_world` → `world_to_ego`），省算力且不引入额外误差。

## 8. 基线冻结（`baseline_check.py`）

- 冻结 config：`BASELINE_ID/WP_*/SIM_DT/RECORD_HZ/TAIL_EXTRA_S/N_LAPS/LAP_SPEEDS/IMAGE_*` 逐项比对，
  改动即 FAIL（提醒这是新基线）；
- 数据不变量：帧数、逐圈帧数/圈时/速度、`num_images`、`|wp0|` 中位与最大、出界/碰撞帧、
  间距误差；v2 共 93 项 + 4 项 sha256；
- `--write-manifest` 写 `baseline_manifest.json`；`--allow-drift` 用于"重录数据"的宽松判定
  （计数 ±2%、`|wp0|` ±0.15 m）；
- 归档 v1 用 `--baseline v1`：不检查当前 config，只核对数据与哈希。

变更政策：任何规格改动 → 新立 `baseline-v3`、新目录、新清单，旧版本只读。详见 [BASELINE.md](BASELINE.md)。

## 9. 该怎么配置

| 想改什么 | 改哪里 | 注意 |
|---|---|---|
| 圈数 / 每圈速度 | 命令 `--laps --speeds`，或 `config.N_LAPS / LAP_SPEEDS_KMH` | 改了要重录 + 新基线 |
| 图像密度 | `config.IMAGE_INTERVAL_S`（0.5=2 Hz，0.2=5 Hz） | 与标签 2 Hz 无关；样本量随之变 |
| 标签时域 / 分辨率 | `config.WP_HORIZON_S / WP_FREQ_HZ` | 改了 `WP_COUNT`，loss 权重长度要同步 |
| 相机参数 | `config.IMAGE_WIDTH/HEIGHT/FOV_DEG/QUALITY` | 改了需重录，且投影校验要看 `viz_waypoints.py` |
| 训练超参 | `training/train.py` CLI（`--lr/--epochs/--batch-size/--hidden-dim/--loss-weights/--smooth-weight`） | 默认即正式配方；改动算新实验 |
| 验证圈 | `--val-laps`（如 `5` 或 `2,4`） | 必须是存在的圈号 |
| 消融 | `--zero-prop` / `--train-stride` | checkpoint 会记录开关 |
| 控制器 | `config.GEO_PARAMS` | 改完先跑 `validate_controller.py` 整圈 |
| 数据路径 | `config.OUT_DIR / MULTI_LAP_*` | npz 与图片目录要一起移动 |

固定常数（不要配）：`prop = [speed/72, steering/0.6]`、损失权重 `[3.0,2.5,2.0,1.5,1.0,0.8]`、
平滑 0.02、梯度裁剪 5.0、dropout 0.1、特征 384 维。

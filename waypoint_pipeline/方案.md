# waypoint_pipeline — 时间 Waypoints 数据 + Waypoints→控制（整圈自测 PASS ✅）

全程无头（`use_render=False`，不弹 MetaDrive/matplotlib 窗口）；代码只在本文件夹，不改外部既有代码。

## 1. 调用方法

| 命令 | 作用 |
|---|---|
| `python3 run_pipeline.py --images` | 一键全管线：采集(含图片)→waypoints→调参→整圈评测→报告 |
| `python3 run_pipeline.py` | 同上但不采图片 |
| `python3 run_pipeline.py --quick` | 90 s 片段调试模式 |
| `python3 run_pipeline.py --skip-collect` | 复用已有 `trajectory_expert.json` |
| `python3 run_pipeline.py --only collect,build` | 只跑指定阶段（collect,build,tune,eval,report 任意组合） |
| `python3 collect_trajectory.py [--quick] [--images]` | 单独跑阶段1 采集 |
| `python3 make_waypoints.py [--traj PATH]` | 单独跑阶段2 waypoints |
| `python3 viz_waypoints.py --frames 1850,1965` | waypoints 叠加到相机图（带数值校验，FAIL 时退出码非 0） |
| `python3 integrate_record.py <record会话目录>` | record.py 会话 → 本管线轨迹格式 |

注意：macOS 下后台运行请用正常终端/工具方式，**勿用 `nohup`**（脱离终端后拿不到 GL 上下文，报 "Could not open window"）。

## 2. 控制器对外调用方式（后续被模型/录制代码集成就靠这个）

```python
import json
from controllers import GeometricController

ctrl = GeometricController(json.load(open("output/best_geo_params.json")))  # 用调好的参数
action = ctrl.compute(wp_ego, speed_kmh, dt=0.1)   # 返回 [steering, throttle_brake]，直接 env.step(action)
ctrl.reset()                                        # 车辆传送/新片段开始时重置调速 PID
```

| 接口约定 | 内容 |
|---|---|
| 输入 `wp_ego` | [10,2]，**当前车辆 ego 系**（x 前、y 左，米，地面点）；世界系需先用当前位姿转 ego（参考 `evaluate.WaypointReplay`） |
| 输入 `speed_kmh` | 当前车速标量 km/h（旋转不变，与坐标系无关）；`dt` 控制周期 0.1 s，每步调一次 |
| 输出 | `[steering, throttle_brake]`：steering 归一化±1→±40° 前轮角（内部已限幅±0.6，正=左转）；throttle_brake∈[-1,1] 正油负刹，与 MetaDrive/record.py 动作约定一致 |
| 依赖 | 仅 numpy；无全局定位；参数可缺省（`GeometricController()` 用 `config.GEO_PARAMS` 默认值） |

## 3. 产物介绍（`output/`）

| 路径 | 内容 |
|---|---|
| `trajectory_expert.json` | 整圈原始轨迹 5611 帧 @10 Hz（字段与 record.py 兼容，另含 `t`、`throttle_brake`；采图帧多 `"image"` 相对路径） |
| `images/`（280 张） | 前向相机 RGB 640×360，**每 2 s 一帧**，`frame_{frame_id:07d}.png` |
| `dataset_waypoints.npz` | 训练数据集，字段见下表 |
| `dataset_waypoints_meta.json` | 数据规格与校验统计 |
| `best_geo_params.json` / `tune_results.json` | 几何控制器最优参数 / 调参扫描记录 |
| `eval_geometric/` | 闭环整圈评测：`metrics.json` + `drive_log.csv` + `eval_plots.png` |
| `report.md` | 自动汇总的自测报告与验收结论 |
| `viz/` | waypoints×图片样例（如 `viz_frame01965.png`） |

`dataset_waypoints.npz` 字段：

| key | shape | 含义 |
|---|---|---|
| `wp_ego` | [N,10,2] | **ego 系 waypoints**（x 前 y 左，米） |
| `wp_world` | [N,10,2] | 世界系 waypoints（闭环评测回放用） |
| `t,x,y,heading,speed_kmh` | [N] | 时间戳与自车状态 |
| `steering,throttle,brake` | [N] | 专家控制标签 |
| `image_path` | [N] str | 对应图片相对路径；**每 20 帧（2 s）一个，其余为空串** |
| `train_mask,val_mask` | [N] | 前 90% / 后 10% 按时间划分 |

`(image_path[i]!="") → (图片, wp_ego[i], speed_kmh[i], 标签)` 即成训练对。

## 4. 方案

### 4.1 数据流

```
PathFollower 专家(无头) ──阶段1──> trajectory_expert.json (+images/)
        ──阶段2 make_waypoints──> dataset_waypoints.npz
        ──阶段3 controllers──> 几何控制器 (Pure Pursuit + PID)
        ──阶段4 tune / 阶段5 evaluate──> 整圈闭环评测 ──> report.md
```

| 规格项 | 值 |
|---|---|
| 控制/记录频率 | 10 Hz（decision_repeat 5 × physics 0.02 s） |
| waypoints | 未来 **5 s @2 Hz = 10 点**（t+0.5 … t+5.0），ego 系（x 前 y 左），米 |
| 图片采集 | 每 **2 s** 一帧，640×360，水平 FOV 60°（`config.IMAGE_*`） |
| 圈尾 | 过终点多录 6 s；闭环按圈周期延拓插值，保证每帧有完整未来 5 s |

### 4.2 阶段1 采集（collect_trajectory.py）

- 专家=项目根 `pid_demo_autonomous.PathFollower`（Pure Pursuit+PID，参考内侧车道中心线 `simple_track_reference_clean.json`）；`LapCounter` 计圈，碰撞即中止，完圈后再录 6 s。
- **图片采集实现要点**（MetaDrive 无头渲染的三个坑，合并 record.py 时同样适用）：

| 坑 | 现象 | 对策 |
|---|---|---|
| 相机被过滤 | `use_render=False` 且 `image_observation=False` 时 `base_env` 直接丢弃所有相机 | 配置 `image_observation=True` 且 `vehicle_config.image_source="rgb_camera"`（默认 main_camera 不存在会 KeyError） |
| 传感器不挂车 | 无 main_camera 时 `reset_sensors` 不把相机 track 到车上，读到旧位姿纹理 | 每次拍摄前手动 `cam.track(v.origin, DEFAULT_SENSOR_OFFSET, DEFAULT_SENSOR_HPR)` 再 `renderFrame()`（见 `traj_utils.capture_rgb`） |
| 离屏窗口 | `nohup` 后台起进程拿不到 GL 上下文 | 正常终端/工具后台运行 |

### 4.3 阶段2 waypoints（make_waypoints.py）

- 对每帧 i，取 `t_i+0.5 … t_i+5.0`，在轨迹 (t,x,y) 上线性插值 → 世界点 → 旋转到 ego 系；
- 闭环轨迹用圈周期延拓（圈尾接圈头），开环片段末尾按最后航向+速度匀速外推；
- 校验：相邻 waypoint 间距 ≈ v×0.5 s，整圈中位相对误差 **0.01%**。

### 4.4 阶段3 控制器（controllers.py，输入：10 点 waypoints + 当前车速）

| | GeometricController（几何法） |
|---|---|
| 横向 | 折线前瞻 `L=base+scale·v`，在 waypoints 折线上按弧长取前瞻点，自行车模型反解前轮角 `δ=atan(2·L_wb·y/L²)`；可选横向 P 项 `kp_steer`（默认 0：ego 系 waypoints 已隐含偏移，再加会重复计数） |
| 纵向 | PID 控速 + 曲率前瞻限速 `v≤sqrt(a_lat/\|κ\|)`（未来 3 s；κ=曲率 1/m，由 waypoints 折线逐段外接圆算，取最大） |
| 量纲 | 前轮角(rad)→归一化动作：动作=δ/max_steering(40°)，限幅 0.6（轮胎饱和标定，见 §4.9） |
| 定位 | 可解释、无需训练、对偏离输入天然有拉回行为（Pure Pursuit 把输入当空间参考线，不检查时间可行性）；将作为真实模型的下游消费端 |

注：输入折线在车辆偏离时原点→首点存在折角（参考路径≠当前状态的自然表达），评测回放 `wp_world` 转当前 ego 系时同样如此，训练/使用分布一致。

### 4.5 阶段4/5 调参与评测（tune_controller.py / evaluate.py）

- 调参：急弯短片段（整圈取 t=185 s 起 60 s）网格扫描 look_base/look_scale；
- 评测：无头闭环整圈，按仿真时刻取 `wp_world` 再用**评测车当前实际位姿**转 ego 系（等价完美预测模型）；直接回放 `wp_ego` 会坐标基准错位、偏差滚雪球（实测 90 s 漂 70 m）；
- 横向误差用 `LateralErrorTracker`（里程索引单调推进；车辆传送/新片段必须 `reset()`，否则虚高 300 m）。

### 4.6 图片×waypoints 可视化（viz_waypoints.py）

投影链：`wp_ego(地面点) → 减相机安装偏移 → 俯视 5° 旋转 → 针孔 u=cx+fx·X/Z, v=cy−fy·Y/Z`。

| 关键细节 | 值 / 做法 |
|---|---|
| 地面高度 | 车辆 origin 在底盘中心，**离地 0.5644 m**（运行时 `v.origin.getZ()` 实测）；地面点 ego z=−0.5644，相机离地=1.5+0.5644=2.0644 m。漏掉此项远处 waypoint 系统性偏上 |
| 数值校验 | 手算公式 vs 引擎相机矩阵 `cam.getRelativePoint`（x右/y前/z上，u=cx+fx·X/Y, v=cy−fy·Z/Y）逐点比对，实测 **≤0.7 px**（容差 2 px）；另查地面点必须在地平线 `v=cy−fy·tan5°` 之下 |
| 已废弃的校验 | DepthCamera 深度缓冲（Mac offscreen 几何不可靠，官方 CI 亦禁用）、锥桶道具（渲染 spawn 位置与引擎投影不符）——勿再使用 |

### 4.7 整圈自测结果（详见 `output/report.md`）

| 项 | 结果 |
|---|---|
| 专家采集 | 5611 帧 / 555.1 s 完圈 / 0 碰撞 / 图片 280 张 |
| waypoints 间距校验 | 中位相对误差 0.01%，外推点数 0 |
| 几何控制器闭环 | 完圈 ✓，平均横向 **0.02 m**（max 0.14），均速 70.0 km/h，0 碰撞 |
| 投影交叉校验 | 直道+急弯帧 max 0.63 px，PASS |
| 出界率 | 与专家基线一致（地图检测在直道段对专家自身约 2.4% 间歇误报，判据=专家基线+0.5%） |

### 4.8 与 record.py 合并（预留）

`integrate_record.session_to_trajectory(records/xxx)`：record.py 会话（frames/*.json @10 Hz）→ 本管线轨迹格式（补 `t`、排序），随后 `make_waypoints.py --traj <file>` 直接出数据集；录制侧只需在录完一圈后调用适配器+`make_waypoints`，相机录制逻辑不变（图片频率坑与 4.2 表一致）。

### 4.9 转向量纲标定（合并时勿改）

MetaDrive 动作 steering∈[−1,1]，实际前轮角=动作×40°。恒转向标定实测：小转向(≤0.1)自行车模型准确；大转向轮胎饱和，横摆率封顶 ~0.5 rad/s，70 km/h 最小转弯半径 ~39 m；整圈最急弯 R64，故限幅必须 **0.6**（旧值 0.08 弯道漂出 44 m）。专家直道转向幅值 ±0.01~0.02，急弯可达 ±0.6。

| `integrate_record.py` | record.py 会话适配器 |

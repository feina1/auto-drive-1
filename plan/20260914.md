## 二、数据 Pipeline

### 问题分析: 原始 PID 数据质量不足
- 原始数据: 16691 帧, PID 循迹录制
- 转向角: 90% < 0.027, 99% < 0.104 → 几乎全是直行微调
- 横向误差: median=0.21m, p90=0.50m → 车辆始终在车道中心
- 结论: 模型学不到"偏移→纠偏"的能力

### 解决方案: 扰动注入录制
- 脚本: `train/record_perturbed.py`
- 策略: 每 3~6 秒施加一次随机扰动
  - 横向偏移: ±0.3m ~ ±1.8m (沿车辆横向)
  - 航向偏移: ±3° ~ ±12°
  - 扰动类型: 40% 纯横向, 20% 纯航向, 40% 两者同时
  - 冷却期: 2 秒 (让 PID 纠偏, 此期间帧即为纠偏样本)
- 录制格式: 与原始数据完全相同 (images + frames + metadata)

### 数据质量对比 (200 帧测试)
| 指标 | 原始 PID | 扰动注入 | 变化 |
|------|---------|---------|------|
| 横向误差 p90 | 0.50m | 0.91m | +82% |
| 横向误差 p99 | 0.96m | 1.45m | +51% |
| 大误差(>0.5m)占比 | 10% | 16.5% | +65% |
| 转向 p99 | 0.10 | 0.20 | +100% |

### 实际录制数据
- 原始 PID: 16690 帧 (`records_pid/2026-09-13_18-22/`)
- 扰动注入: 5932 帧 (`records_perturbed/2026-09-15_00-27/`, 80+ 次扰动)
- 合计: 22622 帧

### GT Waypoint 生成 (V0 中心线 Oracle)
- 在参考路径上找车辆最近点 → 沿路径向前采样 6 个 waypoints (5m, 10m, 15m, 20m, 25m, 30m)
- 坐标系: ego frame (x=前方, y=左方)

### 特征预提取 + 增强
- DINOv3 冻结, 对所有帧一次性提取特征 → 缓存
- 特征 = (CLS_token + mean_pool(patches)) / 2, 维度 384
- 训练时特征增强: Gaussian noise (σ=0.02) + random dropout (p=0.05)
- 多数据源: 原始 PID + 扰动数据合并训练

## 三、模型架构

```
Front RGB [3, 224, 224]
    ↓
DINOv3 ViT-S/16 (frozen, 21.6M params)
    ↓
CLS [384] + mean_pool(patches) [384] → 平均 → [384]
    ↓
Waypoint Head (MLP, 167K params):
    Linear(384 → 256) → GELU → Dropout(0.1)
    Linear(256 → 256) → GELU → Dropout(0.1)
    Linear(256 → 12)  → reshape → [6, 2]
    ↓
Predicted Waypoints [6, 2] (ego frame, 单位: 米)
```

## 四、训练配置

### 超参数
- Batch size: 64
- Epochs: 300
- Optimizer: AdamW, lr=3e-4, weight_decay=1e-4
- Scheduler: CosineAnnealing (T_max=300, eta_min=3e-6)
- Loss: 加权 L2, 权重 [3.0, 2.5, 2.0, 1.5, 1.0, 0.8]
- Train/Val split: 85%/15%
- Skip frames: 2 (每 2 帧取 1 帧)
- 特征增强: Gaussian noise (σ=0.02) + dropout (p=0.05)

### 训练结果
- 最佳 val_l2: **0.318m** (epoch ~185)
- 最终 val_l2: 0.318m
- 数据: 8254 原始 + 1742 扰动 = 9996 帧 (skip_frames=2 后)
- 训练时间: ~60 秒 (特征预提取后)

## 五、闭环测试

### 控制策略
- 模型输出 6 个 ego waypoints
- 加权平均 waypoint 方向 → 目标转向角 (增益 1.5)
- 安全降速: lat_err > 1m → 50km/h, > 2m → 35km/h, > 3m → 20km/h
- 速度 PID: KP=0.15, KI=0.02, 目标 70 km/h
- 安全终止: lat_err > 10m 自动停止

### 首次测试结果
- Frame 0~2000: 正常, 平均误差 0.5~0.7m
- Frame 2200: 误差突增到 41m (某个弯道失控)
- 原因: 模型在某些弯道预测的 waypoints 偏差大, 转向增益过高
- 修复: 降低转向增益 (2.0→1.5), 添加安全降速机制

### Baseline 目标
- 完成 1 圈
- 与 reference_path 偏移不超过 2m

### 渲染优化 (加速闭环测试)
- `image_on_cuda=True`: 避免 CPU-GPU 图像传输
- `multi_thread_render=True`: 多线程渲染
- 窗口尺寸: 480×270 (原 960×540)
- HUD 每 200 帧刷新一次 (原每帧)
